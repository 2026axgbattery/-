### 🤖 Claude · 2026-09-07 20:17

> 🔧 도구 사용: view

VS Code 확장 안의 Claude Code도 CLI와 같은 설정 파일을 공유하기 때문에, 응답 언어는 Claude Code 설정에서 지정하면 됩니다. 방법은 크게 세 가지입니다.

**1. settings.json에 `language` 설정 (권장)**

`~/.claude/settings.json` (전체 적용) 또는 프로젝트의 `.claude/settings.json` (프로젝트만 적용)에 추가:

```json
{
  "language": "korean"
}
```

이렇게 하면 Claude가 응답할 때 한국어를 기본으로 사용합니다. 사람이 읽을 수 있는 언어 이름(예: `"korean"`, `"japanese"`)으로 적으면 됩니다.

**2. Claude Code 안에서 `/config` 명령**

Claude Code 채팅 창에서 `/config`를 입력하면 설정 메뉴가 뜨고, 그 안에서 언어 항목을 바꿀 수 있습니다.

**3. CLAUDE.md에 지시문 추가**

프로젝트 루트의 `CLAUDE.md`에 "항상 한국어로 답해줘" 같은 문장을 넣어두면 해당 프로젝트에서 그대로 따릅니다. 코드 주석이나 커밋 메시지 언어까지 세부적으로 지정하고 싶을 때 이 방법이 유용합니다.

참고로 VS Code 확장 자체의 UI(메뉴, 버튼)는 VS Code의 표시 언어를 따르며, 위 설정은 Claude의 응답 언어만 바꿉니다.

제 정보가 최신 버전과 다를 수 있으니, 설정 항목 이름이 안 먹으면 공식 문서(https://docs.claude.com/en/docs/claude-code/settings)에서 확인해 보세요.

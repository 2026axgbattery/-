## 결론부터

**정해진 배수는 없습니다.** 다만 현장에서 관행적으로 쓰이는 값은 **위험재고(리드타임 소요량)의 1.5~2배** 수준이고, 설비 정지 리스크가 큰 품목은 2~3배까지 갑니다.

이 배수가 나오는 이유는 적정재고가 이렇게 구성되기 때문입니다.

```
적정재고(발주점) = 위험재고(LT 소요량) + 안전재고
```

여기서 안전재고를 위험재고의 50~100%로 잡는 관행이 곧 "1.5~2배"라는 표현이 됩니다. 즉 배수 자체가 원칙이 아니라, 안전재고 계산 결과를 거꾸로 표현한 값입니다.

## 배수를 그대로 쓰면 위험한 경우

배수 방식은 리드타임과 사용량이 안정적인 소모성 자재(필터, 벨트, 오일, 표준 베어링)에는 잘 맞습니다. 반면 다음 경우엔 배수가 실제 필요량과 크게 어긋납니다.

- 리드타임 변동이 큰 품목(수입 자재, 제작품): 평균 LT가 아니라 **최대 LT**가 결함을 결정합니다
- 사용량이 연 1~3회로 드문 품목: 평균 소요량 자체가 의미가 없어 배수 계산이 0.3개 같은 값을 냅니다
- 단가가 높고 사용 빈도가 낮은 예비품: 배수보다 "1개 보유할지 말지"의 판단 문제입니다

## 계산으로 접근하는 방식

```
안전재고 = Z × √(LT × σd² + d² × σLT²)
```

- d: 일평균 사용량, σd: 사용량 표준편차
- LT: 평균 리드타임, σLT: 리드타임 표준편차

| 목표 서비스율 | Z값 |
|---|---|
| 90% | 1.28 |
| 95% | 1.65 |
| 98% | 2.05 |
| 99% | 2.33 |

리드타임 변동이 크면 위 식의 두 번째 항이 지배하게 되고, 이때 안전재고가 위험재고를 넘어서 결과적으로 2배 이상이 나옵니다. 반대로 국내 상시 재고 품목처럼 LT가 안정적이면 1.2~1.3배로도 충분합니다.

## 실무적으로는 등급을 나누는 게 낫습니다

| 구분 | 기준 | 적정재고 |
|---|---|---|
| A (치명) | 고장 시 라인 정지, LT 장기 | 위험재고 × 2~3 또는 정수 예비품 1~2개 확정 보유 |
| B (중요) | 정지는 없으나 성능 저하 | 위험재고 × 1.5~2 |
| C (일반) | 대체 가능, 단납기 | 위험재고 × 1~1.3, 또는 발주점만 관리 |

A등급은 배수 계산 대신 "정지 1시간당 손실액 × 예상 정지시간"과 "예비품 보유비용"을 비교해서 보유 수량을 정하는 게 훨씬 합리적입니다. 배수 규칙은 B, C등급 다품목을 일괄 관리할 때 쓰는 도구로 보시면 됩니다.

혹시 관리하시는 자재의 리드타임 분포나 품목 수를 알려주시면 어느 방식이 맞을지 더 구체적으로 잡아드릴 수 있습니다.

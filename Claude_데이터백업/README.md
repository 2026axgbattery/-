# Claude 데이터 백업

claude.ai 설정 → 개인정보 → "데이터 내보내기"로 받은 자료를 정리한 폴더입니다(내보내기 생성: 2026-09-30 14:17 KST).

| 경로 | 내용 |
|---|---|
| `대화기록/00_목차.md` | 대화 10건 목차 — 제목·날짜·메시지 수 |
| `대화기록/NN_날짜_제목.md` | 대화별 전체 내용(내가 쓴 글과 Claude 답변) |
| `아티팩트_목록.md` | 아티팩트 10건의 제목·설명·날짜 |
| `원본/` | 내려받은 zip 3개 원본(conversations·frames·light_metadata) |

- 대화 파일에서는 시스템이 자동으로 넣은 안내 문구(현재 날짜 등)를 뺐습니다. 빠짐없는 원본은 `원본/conversations-000.zip`에 있습니다.
- `원본/light_metadata-000.zip`에는 계정 정보(이름·이메일·전화번호)가 들어 있으니 공유할 때 주의하세요.
- 이 내보내기에는 claude.ai 채팅만 들어 있고, Claude Code(데스크톱 앱 코드 탭) 작업 대화는 들어 있지 않습니다.
